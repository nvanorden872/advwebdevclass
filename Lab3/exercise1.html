Exercise 1: JSON Structure Exploration

Main Structure

The Open Library book data is organized as a JSON object. The object contains name/value pairs that describe the book.

Name/Value Pair

An example of a name/value pair is:

"title": "Harry Potter..."

The name is "title" and the value contains the book title.

Object

A JSON object is surrounded by curly brackets. 

{
    "title": "Example Book",
    "publish_date": "2020"
}

Array

Arrays contain collections of values and are surrounded by square brackets. 

[
    "Publisher One",
    "Publisher Two",
    "Publisher Three"
]

Nested Structure

JSON can contain objects inside other objects and arrays inside objects. This allows more complicated information to be organized together. 

{
    "book": {
        "title": "Example",
        "authors": [
            {
                "name": "John Smith"
            }
        ]
    }
}

Overall Organization

The JSON is organized as one main object containing information about a book. Some properties contain simple values, while others contain arrays or additional objects. This allows related information to be grouped together.
